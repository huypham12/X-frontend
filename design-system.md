# Design System & UI Guidelines (Threads-inspired)

## 1. Design Philosophy
- **Threads-inspired Interface:** Minimalist, content-first, clean visual hierarchy.
- **Comfortable Reading Experience:** Generous whitespace, large readable text.
- **Modern & Premium Feel:** No visual clutter, subtle and fast animations (150-250ms).

## 2. Color System
- **Theme:** Dark mode first.
- **Primary Background:** `#000000`
- **Secondary Background:** `#121212`
- **Card Background:** `#181818`
- **Border:** Low contrast, thin borders.
- **Primary Text:** White
- **Secondary Text:** Gray
- **Accent Color:** Use primary brand color (e.g., Twitter Blue or neutral White) ONLY for interactive actions. Avoid colorful UI.

## 3. Typography & Spacing
- **Font:** Inter
- **Style:** Large readable text, strong hierarchy, generous line height. No decorative fonts.
- **Spacing System (8px scale):** 4, 8, 12, 16, 24, 32, 48px.

## 4. Layout & Components
- **Layout:** Content centered. Max content width around 600~700px. Responsive (Mobile-first).
- **Component Style:** Rounded corners (e.g., 12px), soft shadow, minimal icons.
- **Strict Prohibitions:** NO heavy gradients, NO glassmorphism, NO neumorphism, NO complex backgrounds.
- **Buttons:** Rounded, medium weight, simple color, no gradient, hover only slightly brighter.
- **Cards:** Flat, thin border, minimal shadow, padding 16~20px.

## 5. Visual Benchmark
- The overall visual quality should feel similar to Threads.
- **When unsure between two designs:**
  - Choose the simpler one.
  - Choose the one with more whitespace.
  - Choose the one with fewer borders.
  - Choose the one that emphasizes content rather than UI.
  - Choose consistency over creativity.
